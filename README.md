# hello_racket-gui

Minimal Racket GUI hello-world program.

## Run

```sh
racket main.rkt
```

## Task Runner

```sh
./ask.sh
```

| ID | Task |
|----|------|
| 1 | Setup - check and install requirements (Linux, macOS, Windows) |
| 2 | Build - `raco exe main.rkt` |
| 3 | Run - `racket main.rkt` |
| 0 | Exit |
